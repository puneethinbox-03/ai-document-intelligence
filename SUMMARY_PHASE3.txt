✅ Step 3: Created Document Schema
Created:

Implemented the DocumentResponse schema:
from pydantic import BaseModel
class DocumentResponse(BaseModel):
    document_id: str
    filename: str
    file_type: str
    file_size: int
    status: str
This defines the response structure returned by the document upload API.
