Important Decision — Should backend/data/chroma/ Be Kept?
YES.
Keep:
backend/data/chroma/
locally.
Do NOT commit its contents to Git.
Reason:

Application
    ↓
ChromaDB
    ↓
backend/data/chroma/
    ↓
Persistent local vector database
The directory is required for the application to persist vectors between runs.
Git should track the code that creates/uses ChromaDB, not the generated database itself.
Therefore:
backend/data/chroma/       → Keep locally
chroma.sqlite3             → Do NOT commit
collection UUID directory  → Do NOT commit
